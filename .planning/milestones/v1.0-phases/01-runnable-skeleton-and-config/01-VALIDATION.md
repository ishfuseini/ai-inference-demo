# Phase 01 - Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest |
| **Config file** | `pyproject.toml` once Wave 0 creates it |
| **Quick run command** | `uv run pytest tests/test_config.py tests/test_imports.py -q` |
| **Full suite command** | `uv run pytest` |
| **Lint command** | `uv run ruff check .` |
| **Estimated runtime** | Less than 30 seconds after dependencies are installed |

---

## Sampling Rate

- **After every task commit:** Run `uv run pytest tests/test_config.py tests/test_imports.py -q` when those files exist.
- **After every plan wave:** Run `uv run pytest` and `uv run ruff check .`.
- **Before `$gsd-verify-work`:** Run `uv sync`, `uv run pytest`, `uv run ruff check .`, and a bounded non-live launch smoke.
- **Max feedback latency:** 60 seconds for automated checks once `uv.lock` exists.
