<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → UI | User selects strategy via NiceGUI dropdown — values constrained to STRATEGIES dict keys, no free-text injection |
| UI → OpenRouter API | Request body includes provider routing params from strategy_payload() — crosses network to external API |
| OpenRouter → Client | SSE response stream with model/provider/usage metadata — parsed by existing client.py |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Spoofing | OpenRouter API key | medium | accept | API key passed via environment variable, not UI input. Existing Phase 1 config guard handles missing key. No new auth surface in Phase 3. |
| T-03-02 | Tampering | Strategy selector values | low | mitigate | Strategy selector is a ui.select bound to STRATEGIES dict — user cannot inject arbitrary strategy names. STRATEGIES.get(name, DEFAULT_STRATEGY) falls back to default for unknown values. |
| T-03-03 | Information Disclosure | provider_preferences in request body | low | accept | Provider routing params (sort: price/latency) are non-sensitive routing hints, not credentials. No secrets in request body beyond existing API key header. |
| T-03-04 | Denial of Service | Fallback primary strategy cost | low | accept | Primary attempt uses nonexistent model with allow_fallbacks=false — fails immediately with 404, zero tokens, zero cost. Only the fallback attempt generates cost. Total cost per fallback run equals one normal run. |
| T-03-SC | Tampering | No new pip packages | high | accept | No new packages introduced in Phase 3. All dependencies existing from Phase 1/2, already verified in Package Legitimacy Audit. |
</threat_model>
