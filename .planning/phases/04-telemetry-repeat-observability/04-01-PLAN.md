<objective>
Deliver the normalized-telemetry vertical slice: a single normal (non-fallback, non-repeat) run records model/provider/latency/tokens/cost **and** cache/repeat + trace-state fields end-to-end from the OpenRouter stream through `TelemetryEvidence` to the UI telemetry panel, and a conditional Langfuse trace helper that never blocks inference.

**As a** forward-deployed engineer demoing production inference, **I want to** see every run carry normalized cache/repeat and trace-state metadata with honest `Unavailable` handling, **so that** cache claims and trace state are visible and defensible rather than assumed.

Purpose: Prove the frozen-dataclass extension, the `X-OpenRouter-Metadata` opt-in, the `prompt_tokens_details` cache predicate, and the conditional-Langfuse pattern all work together before later waves build repeat and comparison on top.
Output: Extended `TelemetryEvidence`/`StreamedResult`, `_extract_cache`, `TraceOutcome`/`record_trace`, Cache+Trace telemetry rows, and the first three test files (one new, two extended).
</objective>
