- **EVAL-01 (unclassified):** The CLI runs 3-5 checked-in cases by default; `load_cases` enforces the 3-5 bound with `ValueError`, and `--limit N` caps runtime cases. Assumed — no SPEC states the default count; taken from REQUIREMENTS EVAL-01 + data-model "three to five".
- **EVAL-02 (adjacency — equal/just-touch elements):** term matching is a case-insensitive substring check (`.lower() in`), so a shorter term that is a substring of another still matches independently (no word-boundary anchoring). Assumed — RESEARCH Pattern 1 specifies `.lower() in`, no boundary requirement.
- **EVAL-02 (empty/single/null input):** an empty response text fails (all expected terms missing); a single-term response passes only if it is the sole expected term and no forbidden term is present; a `None` stream result (stream ended with no `StreamedResult`) yields a failed `EvalResult` with `score_reason="stream ended without a final result"` and `telemetry=None`. Assumed — derived from `score_response` semantics + the `run_repeat_scenario` no-result path.
- **EVAL-02 (ordering — equal elements):** matched/missed/tripped terms and the case grid are reported in the declared `evals/cases.json` order (tuple order preserved); strategy order is the `--strategies`/`--models` argument order. Assumed — no explicit ordering acceptance criterion exists.
- **EVAL-03 (boundary — min/max/threshold):** scoring is binary pass/fail with no score threshold; the boundary is "all expected present AND no forbidden present", one step either side = one missing term or one tripped term → fail. Assumed — RESEARCH Pattern 1.
- **EVAL-03 (precision — rounding/tie-breaking):** cost renders as `$<value:g>` and latency as `<int> ms` (reusing the UI formatters' conventions); summary mean latency rounds to one decimal; total cost is a float sum over non-`Unavailable` values. No tie-breaking exists because pass/fail is boolean. Assumed — no numeric precision contract in the seed specs.
- **EVAL-04 (unclassified):** latency/tokens/cost are passed through from the `StreamedResult` into `TelemetryEvidence`; `Unavailable` values stay the sentinel and are serialized via `TelemetryEvidence.to_dict()` (`"__unavailable__"`), never coerced to zero. Assumed — STATE.md metadata-honesty decision.
- **EVAL-05 (unclassified):** `trace_id`/`trace_url` are rendered only when `trace_status == "enabled"`; `"disabled"`/`"failed"` are reported verbatim from `TraceOutcome.status`. Assumed — mirrors `ui._run_inference` + RESEARCH security domain.
- **EVAL-06 (unclassified):** comparison defaults to strategies `default,cost`; `--models` switches to model-id grouping without touching `routing.STRATEGIES`. Assumed — RESEARCH Open Question 3 recommendation.
