# Vibrant Kinetic Dark

## Vision
A technical, high-performance interface designed for production observability. The theme uses a deep ink canvas with high-energy purple and mint-green accents to highlight critical data, supported by a soft lavender tertiary for subtle depth and secondary information.

## Colors
- **Hero Purple (#8a2be2):** The primary brand and action color. Used for buttons, active navigation, and primary branding.
- **Electric Accent (#2be28a):** A secondary functional color for success states, secondary highlights, and positive technical indicators.
- **Soft Lavender (#E1DAEF):** A tertiary color used for delicate metadata, secondary UI highlights, and subtle borders to soften the technical aesthetic.
- **Dark Neutral (#08050a):** The core surface color for the dark mode canvas.
- **Light Neutral 1 (#FCFDFE):** The primary text color for high-contrast readability against dark surfaces.
- **Light Neutral (#f0ecf9):** A soft tinted neutral for secondary text, labels, and muted UI elements.

## Typography
- **Headlines:** Work Sans — A bold, approachable sans-serif that provides character and clarity for product headings.
- **Body & Data:** JetBrains Mono — A technical monospaced font that reinforces the developer-centric nature of the product, ideal for streaming logs and telemetry.

## Layout & Shapes
- **Corner Radius:** 4px (rounded.DEFAULT) is the standard for cards and inputs, providing a sharp, surgical, and professional feel suited for technical tools. This subtle rounding maintains the precision of a grid-based UI while slightly softening the edges. Pill shapes (rounded.full) are reserved for primary buttons and high-visibility chips.
- **Structure:** Flat design relying on thin borders (often using the tertiary lavender) and subtle color shifts between surface containers rather than heavy shadows.
